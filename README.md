## Descripción

Sporting es una página web de venta de ropa, zapatillas y accesorios deportivos.

## Tecnologías utilizadas

- HTML
- CSS
- Git y GitHub

## Flexbox

Usamos Flexbox en el header para acomodar el nombre de la página y el menú. También lo usamos en contacto y en los enlaces del footer.

## Grid

Usamos Grid en la parte de productos para mostrar las tres tarjetas una al lado de la otra.

## Variables CSS

Creamos variables para guardar colores, fuentes, espacios y bordes. Por ejemplo:

- `--primary-color`
- `--main-font`
- `--spacing-medium`
- `--border-radius`

## Responsive Design

Agregamos una media query para que, en pantallas chicas, los productos queden uno debajo del otro y el header se adapte mejor.
